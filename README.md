# Пармезан

Карманный 3D-бультерьер, который живёт в телефоне. Его можно гладить пальцем, кормить косточкой, кидать ему мячик и просить лапу. Если долго его не трогать, он задремлет и завалится на бок.

## Что умеет

- **Гладить**: водите пальцем по собаке, телефон мягко вибрирует.
- **Косточка, мяч и лапа**: кнопки в нижней панели. Мяч можно перетаскивать и бросать.
- **Дай пять**: попросите лапу и коснитесь её.
- **Сон**: после 90 секунд без касаний он клюёт носом и засыпает на боку. Если гладить его во сне, он не проснётся.
- **Аксессуары**: ошейник с жетоном и серьги качаются с учётом физики.

## Запуск

Это обычная статическая страница. three.js подключается с CDN, сборка не нужна.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Если открыть `index.html` просто как файл, ничего не заработает: браузер не даст загрузить `dog.glb`, поэтому нужен локальный сервер.

Сайт можно опубликовать через GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | Всё приложение: сцена, свет, поведение, вибрация, UI |
| `dog.glb` | Готовая модель со скелетом, весами, текстурами и аксессуарами |
| `source/tripo_model.glb` | Исходная модель из Tripo |
| `source/parts_split.glb` | Та же модель, разрезанная на части (ошейник, жетон, серьги) |
| `tools/rig.py` | Скрипт, который из исходников собирает `dog.glb` |
| `tools/load.py` | Помощник для чтения GLB |

## Пересборка модели

```bash
pip install numpy pillow
python3 tools/rig.py   # перезапишет dog.glb
```

Что делает скрипт:

- ставит кости и считает веса скиннинга;
- чистит текстуры: делает кожу матовой, нос и глаза глянцевыми, убирает оранжевое под ошейником;
- сшивает шов на шее и закрывает дыры;
- добавляет аксессуары отдельными мешами, чтобы они качались.

## Лицензия

Код (`index.html`, `tools/`) можно использовать свободно.

3D-модель (`dog.glb` и всё в `source/`) сделана в [Tripo](https://www.tripo3d.ai/), и на неё распространяются условия Tripo. Для моделей, созданных на бесплатном тарифе, это некоммерческое использование с указанием авторства.
